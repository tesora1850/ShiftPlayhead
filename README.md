# ShiftPlayhead

로직 프로 12.4부터 **트랙 영역 빈 곳을 Shift+클릭해도 재생헤드가 안 움직이는 버그**를 임시로 살려주는 메뉴바 앱이에요.

Shift+클릭하면 앱이 같은 가로 위치의 눈금자를 대신 눌러줘요. 그리고 마우스를 원래 자리로 돌려놔요.

- 리전 Shift+클릭이나 Shift+드래그(영역 선택)는 원래대로 동작해요.
- 로직이 맨 앞에 있을 때만 동작해요.
- 애플이 버그를 고치면 앱을 끄고 지우면 돼요.

## 설치

1. [Releases](../../releases)에서 `ShiftPlayhead.zip`을 받아 압축을 풀어요.
2. `ShiftPlayhead.app`을 **응용 프로그램** 폴더로 옮겨요.
3. 앱을 더블클릭해요. "확인되지 않은 개발자" 경고가 뜨면 **완료**를 눌러요.
   그다음 **시스템 설정 → 개인정보 보호 및 보안**으로 가요. 아래쪽에 있는 **그래도 열기**를 누르면 열려요.
   (애플 개발자 프로그램 공증을 받지 않은 개인 앱이라 이 과정이 필요해요.)
   "손상되었기 때문에 열 수 없습니다"라고 뜨면, 터미널에서 아래 명령을 한 번 실행한 뒤 다시 열어주세요.
   ```bash
   xattr -dr com.apple.quarantine /Applications/ShiftPlayhead.app
   ```
4. 손쉬운 사용 권한을 묻는 창이 떠요. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 ShiftPlayhead를 켜주세요.
5. 메뉴바에 `⇧▶︎`가 보이면 준비 끝이에요.
6. (선택) 맥을 켤 때마다 자동으로 실행하려면 **시스템 설정 → 일반 → 로그인 항목**에 추가하세요.

## 메뉴바 표시

| 표시 | 뜻 |
|---|---|
| `⇧▶︎` | 켜짐 |
| `⇧▷` | 꺼짐 (메뉴에서 켜고 끌 수 있어요) |
| `⇧▶︎?` | 손쉬운 사용 권한을 기다리는 중 |
| `⇧▶︎•` | 새 버전이 있어요 (메뉴의 "새 버전 설치하고 다시 켜기"를 누르면 돼요) |

## 알아두기

- 맥OS 13 이상, 애플 실리콘과 인텔 맥용으로 만들었어요. 애플 실리콘 + 영어 로직 12.4에서만 직접 확인했어요. 인텔 맥과 한국어 로직은 아직 확인하지 못했어요.
- 메인 트랙 창 기준으로 만들었어요. 글로벌 트랙(마커·템포 등)을 펼쳐 둬도 동작해요.
- 손쉬운 사용 권한은 로직 앞에서 Shift+클릭을 알아보는 데만 써요. 인터넷은 GitHub에 새 버전이 있는지 물어볼 때(켤 때와 하루 한 번)와, 사용자가 업데이트를 눌렀을 때만 써요. 묻지 않고 설치하지는 않아요. 코드는 `main.swift` 하나라 직접 확인할 수 있어요.
- 기록은 `~/Library/Logs/ShiftPlayhead.log`에 남아요.
- 개인이 만든 비공식 도구예요. 애플과는 관계없어요.

## 업데이트

새 버전이 나오면 메뉴바 표시 끝에 `•`가 붙어요. 메뉴에서 **새 버전 설치하고 다시 켜기**를 누르면 받아서 바꾸고 다시 켜요. 메뉴의 **업데이트 확인**으로 직접 확인할 수도 있어요.

- 받은 앱이 이 앱과 같은 서명(ShiftPlayhead 전용 인증서)일 때만 설치해요. 다르면 설치하지 않아요.
- 0.2부터 이 서명을 써요. **0.1에서 0.2로 바꿀 때 한 번만** 손쉬운 사용 목록에서 예전 ShiftPlayhead를 빼고 새로 켜주세요. 그다음 업데이트부터는 권한이 그대로 유지돼요.
- ⚠️ **0.1을 쓰는 중이라면, 손쉬운 사용 목록을 건드리기 전에 메뉴바에서 먼저 종료하세요.** 0.1은 켜진 채로 권한을 끄면 키보드·마우스가 멈출 수 있어요(0.2에서 고침).
- 0.1에는 업데이트 기능이 없어서 0.2는 직접 받아야 해요.

## 지우기

메뉴바 `⇧▶︎` → 종료를 눌러요. 그다음 응용 프로그램 폴더에서 앱을 지우면 돼요. 로그인 항목과 손쉬운 사용 목록에서도 빼주세요.

## 직접 빌드

```bash
./dist.sh
```

## 서명 인증서 (만든 사람용)

`build.sh`와 `dist.sh`는 키체인의 **ShiftPlayhead Code Signing** 인증서로 서명해요. 앱의 자동 업데이트도 이 인증서로 서명된 새 버전만 설치해요.

- 처음 만들거나 다시 만들 때는 `tools/new_cert.sh`를 써요. 다시 만들 때는 `tools/new_cert.sh --replace`예요. 백업 파일(.p12)과 비밀번호는 저장소 밖 안전한 곳에 보관해요.
- 다른 맥에서는 백업 파일을 더블클릭해서 키체인에 넣으면 그대로 쓸 수 있어요.
- 인증서를 바꾸면, 이미 배포한 버전은 자동 업데이트로 새 버전을 받지 못해요. 직접 받아야 해요.
